Technology

Built with vanilla HTML5, CSS3, and ES6+ JavaScript. Mapping via MapLibre GL JS and deck.gl. Analytical charts via Apache ECharts and Chart.js. No frameworks, no backend, no database — 100% static and deployable to GitHub Pages.
